# PrimeNest — Nigerian Real Estate Platform

Open `index.html` directly in a browser or use VS Code Live Server.

Pages:
- index.html
- properties.html
- property-details.html?id=1
- contact.html

The site is frontend-only: HTML5, CSS3, vanilla JavaScript, Leaflet/OpenStreetMap, Font Awesome and direct Unsplash image URLs. Filtering, URL-based property details, gallery/lightbox, responsive navigation, maps and client-side form validation are included.
